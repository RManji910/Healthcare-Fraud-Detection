# Healthcare Fraud Detection

## Overview

This project explores the use of machine learning techniques to identify potentially fraudulent healthcare claims using Python.

The analysis focuses on data preparation, feature engineering, model development, and performance evaluation to better understand patterns associated with fraudulent claims.

## Technologies

- Python
- Pandas
- NumPy
- scikit-learn
- Matplotlib
